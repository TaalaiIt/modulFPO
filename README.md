# SmartDev Universal FPO Integration Module (ФПО КР + МойСклад)

Универсальный интеграционный модуль **SmartDev FPO Integration** связывает внешние товароучётные/кассовые системы (профиль v1: **МойСклад Fiscal API 1.0 / Vendor API 1.0**) с фискальным модулем Государственной налоговой службы Кыргызской Республики (**ФПО КР / FiscalConnector**) через локальные кассовые агенты и автономную систему аппаратного лицензирования SmartDev.

> 📖 **Полная техническая документация доступна в файле [DOCUMENTATION.md](file:///c:/smartmag/FPO_module/DOCUMENTATION.md)**

### Принципы разделения ответственности:
1. **Integration Core (`src/core`)**: Полная изоляция от МоегоСклада. Отсутствуют любые термины `X-Lognex-*`, `meta.id`, `retailStore.id`. Core оперирует исключительно `NormalizedFiscalOperation`, `FiscalResult`, `CoreError` и статусами `PROCESSING`, `SUCCESS`, `UNKNOWN`, `FAILED`.
2. **Provider Adapters (`src/providers`)**: Изолированные адаптеры (`moysklad`, `mock`). При подключении 1С, Frontol или Paloma создаётся новый каталог `providers/<newProvider>/` без модификации Core, FPO, Licensing или Agent.
3. **FPO Adapter (`src/fpo`)**: REST-клиент `FiscalConnector` (`localhost:8080`), обработка налогов КР (НДС `VAT_0`, `VAT_12`; НСП `ST_0`..`ST_5`), автоматическое восстановление при `40417` (*NOT_VERIFY_PIN*) и `4011` (*REAUTHORIZATION_REQUIRED*), сверка статуса `UNKNOWN`.
4. **Licensing Subsystem (`src/licensing`)**: Автономный сервер и клиент лицензирования SmartDev: привязка к `hardwareId` (Seat), `activationCode`, `device_token`, контроль провайдеров и РНМ, 24-часовой оффлайн-грейс (`offlineLimitHours`).
5. **Fiscal Agent (`src/agent`)**: Локальная служба на кассовом ПК, исходящее WSS-соединение с Gateway (без проброса портов), локальная диагностика оборудования.

## 🚀 Быстрый старт

### Установка зависимостей:
```bash
npm install
```

### Запуск тестов и проверка архитектурной изоляции:
```bash
# Проверка архитектурной изоляции (отсутствие утечки МойСклад в Core/FPO/Licensing/Agent):
npm run lint:architecture

# Запуск полного набора тестов для всех сценариев UC-01 .. UC-23:
node scripts/run-all-tests.js
```

### Запуск Gateway (Облачный сервис):
```bash
npm run start:gateway
# Gateway слушает порт 3000 (HTTP) и ws://localhost:3000/agent-ws
```

### Запуск локального Агента (Кассовый ПК):
```bash
npm run start:agent
```
